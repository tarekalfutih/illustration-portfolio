# tarekalfutih.se — illustration portfolio

Only this site lives here. The interaction design portfolio (tarekdesign.se) is a separate repo:
`~/Documents/GitHub/My-new-portfolio-2026`.

- One page: `src/index.html`, styles `src/css/site.css`, scripts `src/js/`, images `src/images/`.
- Preview: launch config "illustration" (serves `src/`, port 8070). Build `python3 build.py` (needs Pillow).
- Deploy: commit + push `main`, then `python3 build.py --deploy` (force-pushes `dist/` to `gh-pages`).
- Use `↗︎` (with U+FE0E) for the ↗ arrow, or iPhone Safari draws an emoji.
- Saved state: tag `tested-2026-10-28`.
